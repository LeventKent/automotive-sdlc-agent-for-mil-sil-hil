## Description

Integration test: Verify that the TemperatureOut signal changes over the simulation duration, confirming the model is actively computing temperature values.

**Steps:**

1. Start the simulation
2. Read signal Plant model.TemperatureOut at t=0
3. Read signal Plant model.TemperatureOut at t=5
4. Verify that the value at t=5 differs from the value at t=0
