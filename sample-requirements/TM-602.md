# TM-602 — Test: AlertOut transitions when temperature exceeds high threshold

| Field | Value |
|-------|-------|
| ID | TM-602 |
| Type | systemtestcase |
| Status | draft |
| Created | 2026-05-08 |

## Description

Integration test: Verify that AlertOut changes from 0 to a non-zero value when TemperatureOut exceeds the high threshold (80000 mC).

**Steps:**

1. Start the simulation
2. Monitor signal Plant model.TemperatureOut over 10 seconds
3. When TemperatureOut exceeds 80000, read signal Plant model.AlertOut
4. Verify AlertOut is non-zero (alert active) when TemperatureOut > 80000
