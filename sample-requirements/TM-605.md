# TM-605 — Test: AlertOut remains zero when temperature is within thresholds

| Field | Value |
|-------|-------|

| Type | systemtestcase |
| Status | draft |
| Created | 2026-05-08 |

## Description

Integration test: Verify that AlertOut remains 0 (no alert) as long as TemperatureOut stays within the valid range [0, 80000] mC.

**Steps:**

1. Start the simulation
2. Monitor signal Plant model.TemperatureOut over 10 seconds
3. For every sample where TemperatureOut is between 0 and 80000 (inclusive), read Plant model.AlertOut
4. Verify AlertOut equals 0 at all those sample points
